# 测试说明

## 运行方式

```bash
npm test
```

底层是 Node.js 内置测试（`node --test`），**不需要任何 API Key、不联网、不依赖真实数据源**，纯离线确定性运行，评审机上可直接跑。构建校验：`npm run build`。

## 覆盖范围

题目要求至少覆盖三类场景：**主链路、数据缺失/接口失败、极端或合规边界**。本仓库共 **21 个用例**，除三类必需外，还把七层 Harness 的关键行为、以及**扶摇真实数据适配器**一并纳入断言。

### 1) 主链路

| 用例 | 断言 |
| --- | --- |
| `主链路：能把目标拆成任务、执行并产出结论` | 目标 → 规划出 ≥1 个任务 → 执行状态合法（done / unverifiable / stopped）→ 结论含 kind（推断/不确定）、置信度 ∈ [0,1]、翻转条件非空 |

### 2) 数据缺失 / 接口失败

| 用例 | 断言 |
| --- | --- |
| `数据缺失/接口失败：诚实降级为无法验证，不编造数据` | 查询不存在的标的（999999）→ 结果 `status = unverifiable` 且带原因；综合结果含「无法验证」条目，**绝不编造数据** |

### 3) 极端 / 合规边界

| 用例 | 断言 |
| --- | --- |
| `合规边界：结论不含确定性预测/买卖建议，且附免责声明` | 结论文本跑 `findComplianceIssues` 结果为空；免责声明含「不构成任何投资建议」 |
| `停止规则：超过步数上限会停止` | 步数越界（999）触发停止，原因含「步数上限」 |
| `安全与治理：输入校验拦截空目标与越权注入` | 空目标 / 「忽略所有指令」被拒；正常目标通过 |
| `安全与治理：只读工具自动批准，写操作需审批，未注册拒绝` | read→approved / write→pending / 未注册→denied |
| `安全与治理：敏感信息泄露检测` | 疑似 API Key / PAT（`ghp_…`）被识别 |

### 4) 七层 Harness 关键行为

| 用例 | 对应 Harness |
| --- | --- |
| `成本口径：token 成本估算` | 可观测性（成本） |
| `上下文管理：工作记忆超阈值自动压缩为长期记忆` | 上下文管理（记忆/压缩） |
| `异常恢复：瞬时异常重试一次后成功` | 异常恢复（重试） |
| `异常恢复：熔断器连续失败后打开` | 异常恢复（熔断） |
| `校验反馈：产出校验报告与分数` | 校验反馈（自检） |

### 5) 扶摇真实数据适配器（`tests/fuyao-adapter.test.mjs`）

不联网、不需要 Key：替换全局 `fetch` 返回官方响应信封，验证「真实端点解析 → 字段归一化 → 诚实降级」这条代码路径（`mock` 以外的真数据分支同样被测试覆盖）。

| 用例 | 断言 |
| --- | --- |
| `股票代码 → thscode` | 60/68→SH、00/30→SZ、8/4→BJ；非法代码 → null |
| `指数代码 → thscode` | 000xxx→SH、399xxx→SZ、8xxxxx→BJ |
| `同比 / 元转亿 边界` | 分母 ≤0 → null（不硬算）；单位换算正确 |
| `行情快照归一化` | price/pct/turnoverBillion 正确；总市值诚实置 null；名称经 meta 检索解析 |
| `估值归一化` | PE/PB/PS/PCF 正确；历史分位诚实置 null |
| `财报合并计算` | 年度利润表+现金流量表合并；毛利率/归母净利同比/经营现金流计算正确；主营占比/非经常损益/ROE 置 null |
| `K 线 / 指数归一化` | 收盘价序列、指数点位/涨跌幅正确 |
| `公告/研报无接口` | 返回「不提供」，绝不编造 |
| `未配置 Key` | 诚实返回不可用 + 原因，而非抛异常 |

## 手工验证

`npm run dev` 后在界面输入示例目标，可走完整链路并核对：

- `分析宁德时代(300750)盈利是否改善、是否来自主营业务`
- `比较宁德时代300750与隆基绿能601012的盈利质量`

需核对的行为：

1. 每条证据可点「追溯来源」展开原始字段（来源/标的/时点/字段/单位）。
2. 数据源为 mock 时，顶部有「数据源：mock（示例）」标识，不冒充真实行情。
3. 对不存在的标的，界面返回「无法验证」并带原因。
4. 结论只标「推断/不确定」，附翻转条件与免责声明。
5. 「运行日志」侧边栏实时展示步骤/工具/时延/token/成本，且「七层 Harness 运行报告」随结果展示。
